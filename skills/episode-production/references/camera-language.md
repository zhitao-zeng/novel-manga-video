# 短剧镜头语言与 H3 写法

用机位、运动与焦点安排观众何时看清什么。本文是可选表达库；同一集不需要轮流用齐手法。原文与已核剧本决定人物、事件和知识边界，摄影设计改变观看方式，不为镜头新增剧情事实。source 模式可设计镜头；script 模式执行已采用的机位、切点与时长。

遇到导演名或需要眩晕变焦、低位稳定跟拍、对称甩镜、共同漂浮移动、分割焦点的风格化设计时，读[导演关联镜头风格](director-camera-styles.md)：将称呼展开为剧情目的、路径/焦点与停住条件，并区分既有原理实测和新组合待测。

## 写分镜时落实到当前场景

先确定本场观众要经历的发现、判断或关系变化，以及谁先知道、哪些信息暂时看不见，再安排景别、机位、运动与切点。用实际门窗、座位、遮挡和人物动作检查路径；同一场不同镜头可以承担建立空间、发现细节、观察回应和呈现结果等不同任务。

创作时在已有创作说明中按镜号简述关键选镜：当前信息变化是什么、为什么用这个观看位置/运动/切点，随后落实到各镜的 purpose 与 camera。自审时对照最终镜头正文，修正没有剧情触发的移动、看不清的结果和无法衔接的空间；写出实际修改的镜号。固定观察也可以有充分理由，不靠技巧数量或导演名判断采用质量。

导演关联手法可按下面的观看需求进入详细写法，不必等用户先说出术语：

| 当前观看需求 | 可考虑的设计及详细写法 |
|---|---|
| 认知冲击使熟悉环境显得失衡 | [希区柯克式眩晕变焦](director-camera-styles.md#1-希区柯克式眩晕变焦)：主体大小近似不变，背景比例变化 |
| 随人物逐步接近未知空间 | [库布里克式低位稳定跟拍](director-camera-styles.md#2-库布里克式低位稳定跟拍)：低位、跟随距离与揭示路线明确 |
| 工整关系中突然转移注意 | [韦斯·安德森式构图与切换](director-camera-styles.md#3-韦斯安德森式对称关系与注意力切换)：对称起幅，甩镜或快变焦有落点 |
| 身体稳定而环境流动的抽离感 | [斯派克·李式漂浮移动](director-camera-styles.md#4-斯派克李式漂浮移动)：人物和相机共同平移，区别于随身镜头 |
| 同时读到近处动作与远处反应 | [德·帕尔玛式分割焦点](director-camera-styles.md#5-德帕尔玛式分割焦点)：近远两处同时清晰 |

这些是候选设计；原文、当前情境和可执行路径决定是否采用。涉及该设计时再读链接中的中英文示例和实测边界，不把未验证组合当作可靠模板。

## 选型与交付

先说本镜要交代的关系、信息或结果，再决定观察位置和必要变化。景别控制取景大小，机位控制观看方向，构图控制画内关系，运动控制相机路径，焦点控制清晰位置，剪辑控制镜头与声音的接续。

camera 写成一段可执行说明：为什么这样看 → 起点位置/高度/朝向/景别 → 触发 → 路径与速度或焦点变化 → 终点画面 → 停住时机。固定观察也写清观察对象及保持到的动作或切点。若一直运动到切镜，写切镜时的位置。涉及前景遮挡、反射或拉焦，再交代谁清晰、谁虚化、什么先被遮住、何时露出。

一个主要变化可以承接另一个变化；组合时写明先后和触发，实际动作量适合本镜时长。相机与人物各自怎样移动要分开表达。沿运动过程让观众看懂空间变化，不把固定比例、机械交替景别或统一禁动当作叙事方法。

### H3 镜头正文怎样写

先写这一镜实际看见什么，再补必要的环境与行动。全场站位用来理解空间，不要求每人都以全身再次出现在画内。过肩先写“近处甲仅肩/后脑占左边，远处乙胸像占右边”，不先介绍两人全身站在大石台上；人物卡提供身份与服装，不决定这镜的取景大小。单人近景不为了沿用场景介绍塞入另一个人的完整形象。

运动用画面能够辨认的过程来表达：起点先看见什么，触发后经过哪些观察面或遮挡，终点看见什么，再保持到哪个动作或切点。演员的走动、转身与摄影机的横移、绕行分别写清；若要求原地人物被绕拍，就交代其脚和身体保持同一世界朝向。需要停机时为终点留出可观察的保持段，不能因为写了时间就宣称输出已经准时停住。

光学效果写两端的可见差异。拉焦写“近物清、远脸虚 → 近物虚、远眼清”；变焦写取景放大与前后景对齐关系；眩晕变焦写“主体尺寸近似恒定、背景相对主体明显放大或缩小”。分割焦点还要交代中间距离的模糊区别，不能只要求近远都清晰。术语保留，但不靠术语单独证明效果成立。

这些是表达要求，不是模型必成承诺。核对时分别记录核心手法、人物/道具/动作偏差、终点与停住偏差；生成成功和能完整解码不能替代这些内容判断。多镜剪辑另存源片范围与声画切点，不把后期拼接样片说成 H3 单次原生完成。

## 机位与构图

| 方案 | 怎么拍 | 可承担的剧情作用 |
|---|---|---|
| 过肩 OTS | A 的肩/后脑占前景，拍向 B | 对话、试探、回应；写明是哪一侧肩 |
| 过腰 | 前景 A 的腰、手或道具，与远处 B 同框 | 联系意图、物件与对方反应 |
| 腿间框景 | 从前景人物双腿间看向另一人 | 建立对峙位置、距离和遮挡 |
| 带前景单人 Dirty Single | B 主导画面，保留另一人局部 | 聚焦反应，同时保留对方在场感 |
| 双人/多人同框 | 保留距离、朝向和身体回应 | 靠近、排斥、结盟；不必逐句切单人 |
| 低机位仰拍 | 相机低于主体、向上看 | 体量、登场或地位变化 |
| 高机位斜俯拍 | 从上方斜看人物 | 处境、孤立、观察关系 |
| 垂直顶拍 | 从正上方看地面与站位 | 包围、出口、路线或操作步骤 |
| 主观视角 POV | 模拟角色眼睛位置与朝向 | 搜索、进入空间、同步发现 |
| 荷兰角 Dutch Angle | 保持倾斜的地平线 | 异常、失衡、不安；不等于持续滚转 |
| 框中框 | 门窗、栏杆等框住人物 | 限制、距离、观察与被观察 |
| 反射构图 | 利用本场已有镜面/水面 | 同时组织正面与身后信息；反射仍是同一人 |
| 留白 | 人物偏在一侧，另一侧留出空间 | 等待、孤独、尚未出现的信息 |
| 前中后景分层 | 物件、行动人物、旁观者处在不同深度 | 同时组织行动、反应与危险 |

过腰描述前景关系，牛仔景别描述主体取景范围；不要混用。俯拍、仰拍的情绪含义取决于具体剧情，不由角度单独决定。

## 相机运动

| 方案 | 实际运动 | 可承担的剧情作用 |
|---|---|---|
| 推近 Dolly In | 相机接近主体，空间透视随之改变 | 决定、反应、关键细节 |
| 拉远 Dolly Out | 相机离开主体 | 揭露环境、扩大处境、孤立 |
| 横移 Truck | 相机向侧面平移 | 越过遮挡、并排关系、逐步揭示 |
| 水平摇摄 Pan | 原位置向左/右转动 | 随视线从 A 看向 B |
| 俯仰摇摄 Tilt | 原位置向上/下转动 | 从脸到手中物件，或交代高度 |
| 垂直升降 Pedestal | 整台相机向上/下移动 | 改变观看高度、从低处揭露人物 |
| 跟拍 Tracking | 随主体走动，指定前/后/侧面关系 | 赶路、追赶、搜索；交代距离变化 |
| 弧移 Arc | 绕主体走一段弧线 | 从背侧转正面、改变信息与关系 |
| 环绕 Orbit | 围绕主体持续运动 | 主体保持突出，环境连续显露 |
| 摇臂 Crane/Jib | 升降伴随较大范围位移 | 从人物扩展到人群、建筑、地形 |
| 手持 Handheld | 保留细微或明确不稳定 | 仓促、临场、失控；幅度接剧情 |
| 稳定移动 Steadicam/Gimbal | 平滑跟随或穿行 | 连续行动、流畅进入空间 |
| 固定观察 Static | 相机位置与朝向保持不变 | 等待反应，由人物/环境造成变化 |

摇摄改变朝向，横移改变位置；上摇改变观看方向，升高改变相机高度。相同的路径可用不同速度表达不同节奏。先写触发和结果，再决定匀速、加速或减速，不为运动本身凑动作。

## 焦点与镜头效果

| 方案 | 清晰位置或取景怎样变化 | 可承担的剧情作用 |
|---|---|---|
| 浅景深 Shallow Focus | 主体所在距离清晰，其他距离虚化 | 表情、手部、单个线索 |
| 深景深 Deep Focus | 前后较大范围都清晰 | 同时看见行动与后景事件 |
| 焦点切换 Rack Focus | 清晰位置从 A 转到 B | 从线索转到知情者，从人物转到来人 |
| 持续跟焦 Focus Tracking | 主体远近变化，仍维持其清晰 | 人物接近、后退、穿行 |
| 变焦 Zoom | 相机不必移动，焦距改变取景大小 | 细节、刻意的观察感 |
| 急变焦 Crash Zoom | 快速变焦放大或缩小 | 突发发现、强调、喜剧回应 |
| 眩晕变焦 Dolly Zoom | 相机移动与反向变焦配合，主体大小近似不变 | 震惊、恐惧、现实感变化 |
| 分割焦点 Split Diopter | 近远两块区域清晰，中间可模糊 | 同画面容纳两处相关信息 |

拉焦改变清晰对象，变焦改变取景大小，推轨改变相机位置。深景深的清晰范围较连续；分割焦点不要求中间距离也清晰。H3 指令要描述所需可见效果，不假定生成模型真的使用某个镜头附件。

## 组合揭示与表现手法

| 方案 | 路径或过程 | 要交代的内容 |
|---|---|---|
| 背后绕前揭示 | 从人物背侧沿一侧绕到正面 | 表情/身份/身后的人在哪个位置被揭露 |
| 多角色接力展示 | 经过 A、B，再转向 C | 人物顺序、各自触发动作及最终注意落点 |
| 遮挡后揭示 | 横移/弧移越过柱子、树干、门框 | 原先遮住什么，何时看清 |
| 穿门探入 | 从门外沿已存在的通道进入 | 路径、转弯、最终观察对象 |
| 快速甩镜 Whip Pan | 从 A 快速摇向 B，途中模糊 | 触发、方向、最终对象与停住时机 |
| 机身滚转 Roll | 绕相机观看方向轴旋转 | 旋转幅度、结束方向与剧情原因 |
| 主体中心随身 Snorricam | 相机相对身体保持稳定，背景随行动变化 | 脸部构图、背景运动与主观压力 |
| 子弹时间 Bullet Time | 动作极慢，视角仍显著变化 | 被强调的动作瞬间及视角路径 |

“反向包抄”“迈克尔贝式环绕”等风格或通俗名称不能单独决定路径。把它们还原为绕行中心、经过人物、信息出现顺序和终点。轴线服务空间理解；连续绕行可以重新建立方向，不能将画面左右当成固定世界位置。

## 多镜衔接

| 方法 | 前后镜关系 | 用途 |
|---|---|---|
| 正反打 | 从 A 的覆盖切到 B 的覆盖，视线对应 | 对话、试探、回应 |
| 视线匹配 | 看见人物看，再看见他所看的对象 | 发现、判断与反应的因果 |
| 动作匹配 | 换角度接住同一次动作 | 保留连续性，不重新演一遍 |
| 反应镜 | 事件/话语后拍受影响者 | 结果、关系与情绪变化 |
| 细节插入 | 单独取景手、物件或局部操作 | 关键证据、动作结果 |
| Match Cut | 形状、构图或运动相似地跨镜连接 | 时间/场景变化与观念关联 |
| J-cut / L-cut | 新场声音提前，或旧场声音延续 | 声画错位衔接 |

剪辑方式不等于单镜相机运动。当前逐段生成不提供跨请求声音记忆，不靠 J/L-cut 或声音桥承担必须听懂的信息；超短插入镜仍需后期切分支持。手册不会改变当前片段时长与声音接口。

## 六个原创写法示例

### 过肩推近

为看清乙的回应，从甲右肩后的双人中景开始，甲肩膀留在前景左侧。乙伸向茶杯的手停住时，相机沿乙的方向缓慢推近至中近景；乙抬眼看向甲时停住，保持到切镜。

English camera body: From behind Subject 1's right shoulder, begin in a medium two-shot with the shoulder at the left foreground. When Subject 2's reaching hand pauses, dolly slowly toward Subject 2 into a medium close-up. Stop as Subject 2 raises their eyes, then hold through the cut.

### 过腰关联道具

从甲腰侧高度观察，甲手中钥匙占前景右下方，乙在门边中景。甲把钥匙放到桌上时，小幅横移，保持钥匙与乙面部之间的可读关系；乙伸手接近钥匙时停住。

### 背后绕前

从人物左后方中景沿左侧缓慢弧移，逐渐露出她的脸与手中捏紧的信封；面部完整进入侧前方构图时停住。人物保持原朝向，不用人物转身替代相机绕行。

English camera body: Begin behind Subject 1's left shoulder. Arc around their left side to a front three-quarter medium shot, progressively revealing the face and the envelope in their hand. Subject 1 keeps the same world orientation. Stop once the face is fully revealed.

### 拉焦揭示来人

相机在桌沿高度保持静止。前景戒指清晰，后景门边人物虚焦；门把手转动时，焦点从戒指平滑转到来人的脸。脸清晰后保持，戒指成为模糊前景。

English camera body: Hold the camera still at table height. Begin with the foreground ring sharply focused and the person at the doorway blurred. As the handle turns, rack focus from the ring to the person's face. Hold the face sharp while the ring becomes soft foreground.

### 顶拍揭露站位

从主角正上方顶拍，先容纳主角与最近两人；主角后退时缓慢升高，露出其余人和门口位置。所有相关站位与出口可辨认时停住。

### 多角色接力

从桌旁甲的侧前方中景开始。甲将文件推向乙时，沿桌边横移，将注意转给乙停在半空的手；乙望向窗边丙时，继续小幅弧移，让丙进入构图。丙放下杯子时停住，其他人物仍处在可理解的空间关系中。
