segments.json章节输入流程规划、编译、审查、源证据复核本集原文及引用定位。
chapter_script.json规划 / 已采用的修复候选编译、准备、审查结构化剧本；不是最终发送的模型请求。
clip_plan.json打包、请求准备 / 修复写回生成、缓存匹配、审查片段、原文映射、参考绑定和当前请求。
series_assets/manifest.json资产流程参考选择、生成、审查已有素材记录；实际使用以本次请求为准。
work/clips/…/attempt_*供应商与片段生成 / 分析缓存、合成、审查真实尝试的素材及记录；以报告的 selected 确认采用哪条。
thin_media_report.json渲染编排；审查更新验收摘要审查、修复、批量与看板片段结果、技术状态、合成结果与 quality_review。
episode_review.json
review_feedback.json		审查 / 修复反馈流程候选选择、修复、请求准备审查证据及处理意见；反馈存在不等于修复已经完成。
repair_history/history.json修复与生成历史流程候选选择、预算、恢复与统计实际生成、尝试与复核历史；缓存复用不算新生成。

哪些检查发生在哪里，没过会怎样

“review”并不是只有一种检查
检查检查对象执行方式失败去向
剧本结构 / 原文尚未生成视频的分镜程序约束，相关语义检查用模型规划补丁、原有重试或记录阻塞；不直接重拍。
在场 / 姿态连续性原文、人物资料、本镜和相邻镜头模型判断 + 现有归类策略进入允许的规划修订或记录问题；不凭程序猜站位。
最终请求一致性中文、英文与实际参考图视觉模型，程序解释和复用结果明确冲突先处理输入；细节不足不直接当作冲突。
语音检查视频实际音轨与预期台词ASR + 现有语音规则按通道、小说策略、预算修正或重试；不是内容审查的替代。
成片技术质检视频、音轨、字幕、封面片尾媒体工具与程序记录技术不通过；小说级豁免决定部分指标是否阻断。
片段内容审查实际画面、原文和当前计划视觉判官 + 分级 / 终裁路径只审查则保存反馈；自动审修则按原因路由。
修复候选检查候选剧本 / 请求与原版本原有程序及模型检查无有效修改或未通过时不发布该候选，不把准备算成生成。
整集叙事质量整集连起来的因果、节奏、接缝与观感需另行完整验收不能从当前逐片段 review 全通过推断整集讲得清楚。
