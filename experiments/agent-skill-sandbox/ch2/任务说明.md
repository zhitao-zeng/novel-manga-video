# 任务说明

把 `input/source.txt`（长篇小说《盛唐天工》第二章全文）改编成**长篇系列短剧的第二集**，并做成可以交给 AI 视频模型逐镜生成的分镜表。

## 目标

- 一集约 **100 秒**，**16:9 横屏**，**3D 动画**。
- 这是系列第二集。前情和下一集的内容见 `input/前情与下一集.md`。

## 忠于原著

- 人物、事件、因果和结局以原文为准；不新增人物，不新增原文没有的情节。
- 可以删减作者议论、科普和重复解释。
- 讲述顺序可以按你的设计调整（冷开场、闪回等都可以），但事实不能改变。
- 原文里的心理活动要转换成观众能看见或听见的表达。
- **集末钩子**只能指向 `input/前情与下一集.md` 里写的下一集内容，不能为了钩子新编情节，也不能把下一集的事件拍进本集。
- 动物保持原文的物种和身份，不拟人化成会说话的角色。

## 视频生成的限制

- 每个镜头单独生成，**单镜不超过 15 秒**。
- 画面里不要出现可读的文字。
- 人物造型、画风和场景见 `input/人物与画风.md`。

## 交付物（全部写进 `output/`）

1. 编剧 Skill 各步骤的产出，最终剧本写成 `output/01_剧本.md`。
2. 导演 Skill 各步骤的产出，按它的步骤编号命名（例如 `output/03_节奏规划.md`……）。
3. 最终分镜表 `output/分镜表.md`：按导演 Skill 的标准列格式，每镜一行，写明每镜时长。
4. 能生成 xlsx 的话，同时输出 `output/分镜表.xlsx`（需要的 Python 库可以自己用 pip 安装）。
5. `output/运行记录.md`：简要记录每一步做了什么、替用户做了哪些选择以及理由。
