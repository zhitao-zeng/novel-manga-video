# 人物与画风

## 画风

- 统一的 3D 动画，人物与场景使用同一套简化材质。
- 色调：草木绿与岩石灰。
- 画幅：16:9 横屏。

## 人物与动物（本章出场，来自本书的演员表）

**沈行舟**（主角，唯一的人类）

- 男，原本是有妻子和儿子的成年人、在西北荒原讨生活十五年的机械技师；穿越后身体变成了约 18 岁的少年。
- 已确定的造型：短黑发的清瘦少年；过大的深色户外夹克、灰色内衫、深色长裤、棕色靴子；随身有背包、工兵铲、小刀、平底锅等现代装备。
- 注意：已确定的造型是**短发**，不要写成长发或扎发。

**青狼**（动物，狼群中的狼）

- 体型硕大，毛色青灰，吻部较长，眼神凶狠。

**马王**（动物，野马群的头马）

- 体型高大神骏，肌肉线条流畅，毛色枣红，鬃毛浓密飘逸，眼神威严。
