# 人物与画风

## 画风

- 照参考视频《一表千金》（小云雀制作）的画风：**唯美精修的美型半写实 3D CG**，像 3D 乙女游戏的过场动画。
- 人物：偶像式的美型脸；皮肤白皙光润，带柔和的光泽；眼睛适度放大、有神，虹膜清晰，有眼神光；鼻子小巧精致，嘴唇柔润；头发是大块柔软的发束，细碎的发丝透光。
- 光线：柔和的主光，加暖色轮廓光和轻微的光晕，浅景深。服装、皮革、金属的细节清楚，但干净，不粗粝。
- 不是扁平卡通，不是朴素的 3D 游戏模型，也不是照片；没有描边。
- 画幅：16:9 横屏。

## 人物

**沈行舟**（主角，本集唯一正面出场的人物）

- 男，原本是有妻子和儿子的成年人、在西北荒原讨生活十五年的机械技师；穿越后身体变成了约 18 岁的少年。
- 已确定的造型（角色卡已画好）：约 18 岁，清瘦，身高约 1.6 米，手腕和手都很细。瘦长的鹅蛋脸，窄下巴，皮肤白皙；杏仁形的深棕色眼睛，神情平静，带着一点和年龄不符的疲惫；眉毛细而直；短黑发，额前是凌乱的细碎刘海。
- 服装：过大的炭灰色连帽外套（帽子放下）、灰色圆领内衫、深色长裤、棕色皮质登山靴。
- 各阶段的样子：
  - 刚醒来：没穿衣服，拍法见任务说明，只拍到裸露的肩膀。
  - 从泉水里捞回衣服后：还是这一套，湿透了，颜色变深，贴在身上；头发潮湿。
  - 衣服在红砂岩上晒干后：还是这一套，干净干爽。
  - 赶路途中：衣服上有灰、有褶，裤腿到膝盖都被水打湿，靴子沾泥；右脸颊有两道细细的红色草叶划痕；背着半人高的橄榄绿帆布背包，背包侧面挂着折叠工兵铲。
- 注意：原文有"反手抓过披散在肩上的头发"，但已确定的造型是**短发**。请用不依赖长发的动作表达同样的意思，不要改造型。

**家人**（原文里只在他的回忆和梦里出现）

- 妻子（造型已画好）：三十出头的现代中国女性，温婉知性。柔和的鹅蛋脸，温暖平静的微笑；齐肩的深棕色头发，别在一侧耳后；淡妆。奶油色针织开衫、浅蓝色衬衫、米色长裙、平底鞋。
- 儿子、母亲：还没有造型。要表现他们，就用声音、背影或画外处理，不要拍正脸。

## 场景

- 西北荒原：碧绿草地，榆树和槐树，远处山峦
- 溪流源头：草丛中的泉口、清溪和岸石
- 红砂岩营地：溪流附近晒热的红砂岩平地，可搭帐篷和生火
- 溪谷沙地：沿溪前行的茅草、浅水和红沙地
- 故乡盆地：山脚溪流转弯后展开的草原，野马、黄羊、野鸟；这里本该是他家乡的城市，现在只有草原
- 戈壁水潭：穿越之前补水的水潭，水下曾有金色反光（只可能出现在回忆里）
