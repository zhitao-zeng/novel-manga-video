# 任务说明

把 `input/source.txt`（长篇小说《盛唐天工》第一章全文）改编成**长篇系列短剧的第一集**，并做成可以交给 AI 视频模型逐镜生成的分镜表。

## 目标

- 一集约 **100 秒**，**16:9 横屏**，**3D 动画**。
- 这是系列第一集：观众看完要明白主角遇到了什么、为什么崩溃，并想看下一集。

## 忠于原著

- 人物、事件、因果和结局以原文为准；不新增人物，不新增原文没有的情节。
- 可以删减作者议论、科普和重复解释。
- 讲述顺序可以按你的设计调整（冷开场、闪回等都可以），但事实不能改变。
- 原文里的心理活动要转换成观众能看见或听见的表达。

## 视频生成的限制

- 每个镜头单独生成，**单镜不超过 15 秒**。
- 画面里不要出现可读的文字。
- 人物造型、画风和场景见 `input/人物与画风.md`。

## 交付物（全部写进 `output/`）

1. 按所用 Skill 自己的流程，把每一步的产出写成文件，文件名带步骤编号。
2. 如果 Skill 本身没有"从小说到剧本"的步骤，可以先简要整理分场，写成 `output/01_分场.md`，再按 Skill 的方法做分镜。
3. 最终分镜表 `output/分镜表.md`：按 Skill 规定的格式，每镜一行，写明每镜时长。
4. 能生成 xlsx 的话，同时输出 `output/分镜表.xlsx`（需要的 Python 库可以自己用 pip 安装）。
5. `output/运行记录.md`：简要记录每一步做了什么、替用户做了哪些选择以及理由。
