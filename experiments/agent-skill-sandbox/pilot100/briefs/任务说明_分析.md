用 `short-drama-novel-analyze` 把《伏天氏》前 100 章拆成原著分析（S1–S5），再用 `short-drama-develop`
写创作简报和故事引擎，最后按下面的"导出格式"把人物、别名和外观阶段导出成 JSON。

这是一次试点，结果要和我们现有流水线的"建圣经 + 逐章读书"逐项对比。请严格按 Skill 自己的规则做，尤其是：

## 导出格式（S4 完成后写，放在 `output/export/`）

这三份 JSON 用来和流水线的产物机械对比，字段名照写，内容来自你的 S4 结果。

**1. `story_bible.json`**

```json
{"characters": [
  {"name": "正名",
   "aliases": ["有同指证据的别名"],
   "tier": "主要|重要|次要|龙套",
   "gender": "男|女|未写明",
   "age": "原文写明的年龄或年龄段，没有就写 未写明",
   "identity": "身份、所属势力（原文有据）",
   "appearance": "原文有据的外貌，没有就写空字符串",
   "wardrobe": "原文有据的服装，没有就写空字符串",
   "first_chapter": 1,
   "chapters": [1, 2, 5],
   "evidence": [{"chapter": 1, "quote": "不超过 30 字的原文"}],
   "unresolved": ["未决的指代或矛盾"]}],
 "locations": [
  {"name": "地点名", "description": "原文有据的描写", "first_chapter": 1, "chapters": [1, 3]}]}
```

只收有名有姓、或有台词且不止一章出现的人物。泛称（少年、老者、护卫）不单独收，除非它是某个具名人物的唯一称呼，
那就作为这个人物的别名。`chapters` 是这个人物在原文里出场（被叙述或说话）的全部章，不是被提到名字的章。

**2. `bible_aliases.json`**：`{"别名": "正名"}`，只放有同指证据的：专名变体、证据充分的绰号、带姓名的头衔。

**3. `phases.json`**：前 100 章里外观、形态或身份发生**持久**变化的人物（换一身长期穿的衣服、受了长期可见的伤、
变身、身份公开等）。一场戏里的临时状态不算。

```json
{"policy": "phase-cards-v1",
 "characters": {"正名": [
   {"from": 起始章, "to": 结束章或 null, "label": "阶段名",
    "appearance": "这一阶段原文有据的外貌", "wardrobe": "这一阶段的服装",
    "evidence": [{"chapter": 1, "quote": "不超过 30 字的原文"}]}]}}
```

没有这样的变化就写 `{"policy": "phase-cards-v1", "characters": {}}`。
