# 任务说明：《伏天氏》第 1–100 章人物归并（试点）

前一步已经把这 100 章逐章读过。每一章只做了四件事：照抄原文里出现的人物称谓（不做跨章判断）、摘录外貌描写、
记下持久变化、写一句话摘要。结果汇总在 `input/candidates.md`；机器可读的完整版是 `input/candidates.json`，
逐章的原始结果在 `input/extract/`。

你的工作是像责任编辑一样决定"谁是谁"：把指同一个人的称谓并成一个人物，给出正名、别名、性别、年龄、身份、外貌和出场章，
再导出成我们流水线用的 JSON。

## 规则

按 `.claude/skills/short-drama-novel-analyze/references/aggregation-and-entities.md` 的"人物归并"一节：

- 一人一实体。拿不准两个称谓是不是同一个人，就分开建两条，把疑问写进 `unresolved`。
- 只有专名、有同指证据的绰号、带姓名的称呼可以合并成别名。
- **共现不是同指。** 一句里同时出现两个称谓，只说明这句提到了两个人。"甲和乙有关系""甲和乙联姻""甲是乙的人"这类**关系陈述是两个人的证据，不是同指证据**；
  同姓、同出身、同阵营、同一场合在场也都不是。同指要的是两个称谓互换之后整句仍然成立——"甲即乙"的直陈句，
  或者同一段里交替用两个称谓指同一个动作的主语。找不到这样的句子就分开建两条，写进 `unresolved`。
- 描述性称谓（"中年""红衣女子"）和不带姓名的头衔（"院长"）不单独建人物，也不当别名；某一章原文明确写了它指谁
  （候选表"本章原文确认的指向"一列），就作为证据记在那个人物下。
- 亲属称谓（"老爹"）：原文确认指向某个具名人物时，并进去当别名；没确认就不收。
- **原文始终没给名字、但反复上镜的人要单独建条目**：同一个描述性称谓或头衔在 3 章以上指的确实是同一个人
  （回原文核对上下文），就用原文的叫法当正名建一条，`name_source` 写 `"描述"`。例如义父、鹰眼中年、
  南斗国公主、雷行宫宫主。他们要画卡，漏掉就没法出镜。拿不准是不是同一个人，按上一条分开建并写进 `unresolved`。
- 候选表里"原文出现"只是字符串计数：同一个词可能指不同的人，也可能根本不是人名。判断时回原文看上下文
  （`grep -n` 查 `input/伏天氏_1-100.md`）。
- 硬事实（年龄、性别、身份、在哪几章出场）必须能追溯到原文；原文没写的写"未写明"，不按常理补。
- 明显不是人物的（功法、称号、概念、群体）不收。
- 不要用子代理，不要联网，只读原文和候选表。

## 导出格式（放在 `output/export/`）

**1. `story_bible.json`**

```json
{"characters": [
  {"name": "正名",
   "name_source": "原文|描述",
   "aliases": ["有同指证据的别名"],
   "tier": "主要|重要|次要|龙套",
   "gender": "男|女|未写明",
   "age": "原文写明的年龄或年龄段，没有就写 未写明",
   "identity": "身份、所属势力（原文有据）",
   "appearance": "原文有据的外貌，没有就写空字符串",
   "wardrobe": "原文有据的服装，没有就写空字符串",
   "first_chapter": 1,
   "chapters": [1, 2, 5],
   "evidence": [{"chapter": 1, "quote": "不超过 30 字的原文"}],
   "unresolved": ["未决的指代或矛盾"]}],
 "locations": [
  {"name": "地点名", "description": "原文有据的描写", "first_chapter": 1, "chapters": [1, 3]}]}
```

**`quote` 必须是从标注的那一章原文里连续复制的一段**，不得改写、概括、拼接，也不要用省略号把两处接起来。
"叶伏天在紫微宫当众斩杀韩墨弟子穆云轩"是情节复述，不是引文。复制不出连续原句时，换一章能直接复制的，
或者把这条证据删掉——宁可少一条证据，不要一条对不上原文的证据。这条对有名字和没名字的人物同样适用。

只收有名有姓、或有台词且不止一章出现的人物，以及上面那条规则里"没有名字但 3 章以上反复上镜"的人物。
`chapters` 是这个人物在原文里出场（被叙述或说话）的全部章，不是被提到名字的章。

**未成年人（原文写明年龄不满 18，或身份是学宫学生一类）的 `appearance` 和 `wardrobe` 一律不写身材。**
禁止出现胸、腰、臀、腿、曲线、身材、凹凸、丰满、纤细、玲珑、婀娜一类词，也不要用"身姿""体态"绕开；
只写脸、发、神态、衣着款式与颜色。即使原文写了，也不照抄。

**2. `bible_aliases.json`**：`{"别名": "正名"}`，只放有同指证据的。

**3. `phases.json`**：外观、形态或身份发生**持久**变化的人物（长期换装、长期可见的伤、变身、身份公开）。
一场戏里的临时状态不算。

```json
{"policy": "phase-cards-v1",
 "characters": {"正名": [
   {"from": 起始章, "to": 结束章或 null, "label": "阶段名",
    "appearance": "这一阶段原文有据的外貌", "wardrobe": "这一阶段的服装",
    "evidence": [{"chapter": 1, "quote": "不超过 30 字的原文"}]}]}}
```

没有就写 `{"policy": "phase-cards-v1", "characters": {}}`。

**4. `volumes.md`**：第 1–50 章、第 51–100 章各写：主线（五句以内）、未了结的线索（每条一行，写明在哪章埋下）、
主要人物在卷末的处境。依据候选表里的"每章一句话"，需要时回原文核对。

## 另外写到 `output/`

- `report.md`：每个合并和拆分的决定，写依据（章号加原文短引）；最后写你没把握的地方。
- `运行记录.md`：做了什么、按什么顺序、遇到的问题。
