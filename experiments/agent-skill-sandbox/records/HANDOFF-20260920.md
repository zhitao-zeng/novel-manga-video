### 2.2 第一次让流水线给伏天氏写剧本

流水线从没给这本书出过剧本。现跑：

```
scripts/plan_chapter_thin.py <source> --novel-id futian-p100 --title 伏天氏 \
  --bible .../futian-p100/story_bible.json --output-root .../pilot100/pipeline \
  --episode-index 1 --style 3d --frame 16:9 --max-redo 3
```

脚本 `pilot100/plan_fts_ch1b.sh`，纯本地 Qwen 免费。

**默认两次尝试会失败**：两稿分别估 134.0 秒和 146.5 秒，都超 105 秒上限，第二稿比第一稿还长；另有 4 处 `source_quote 不是原文`。加 `--max-redo 3` 重跑第一次就过了。同一提示词两次结果差这么多，这一关是靠运气过的。

产物的三个结构性问题：

1. **硬性禁止内心独白**。`src/novel_manga/planning/constants.py:128` 写着「成片没有旁白、没有内心独白」，`DELIVERY_MODES` 六档里没有内心独白；:129 还写「内心独白不要改成出声自语，改成可见反应」。所以原文两处心声被整个删掉。
2. **一镜一句**。13 镜 13 句共 147 字，它自己的报告都写 `spoken_chars 147 outside 220-300`。后果是问答被拆散：第 6 镜秦伊问「学宫是在什么背景下创立？」**叶伏天始终没答**；第 13 镜「想做什么，都行！」前面没人提过赌约。
3. **事件文字拼接 bug**。`主要事件` 由 `<事件><对象>` 直接相接，13 镜里 5 镜出现「秦伊走向叶伏天**叶伏天**」这种。格式缺陷，会原样进提示词。

### 2.5 内心独白（**已解决**）

官方规范 `VIDEO_PROMPT_WRITING_GUIDE_base_en.md` 4.4 节要求用**一字不差**的短语 `says in an off-screen voiceover`，`<d>` 紧接其后，然后接闭嘴句。我第一版写成 `is heard in an off-screen voiceover` 并在中间插了音频引用，三处都偏了，已改对。

**但改对之后仍然关不掉口型。** 用能量断句定位心声那一段抽帧：秦伊「我的语气，是不是太重了些……」落在 12.0–12.9 秒，12.25 / 12.40 / 12.54 秒嘴明显张着。挂白模和不挂白模两版都一样。

> 我第一次汇报时只说「按官方写了」就当成解决，没有验收。**写法合规 ≠ 口型关上。**

**可靠做法**是 `render/inner_mix.py`，四步：

1. 把心声那句从视频请求里**整个拿掉**（同镜的普通台词保留），motion 末尾追加「没有人把这个念头说出口，想的人嘴唇不动」
2. 渲这一镜 → 纯表演
3. 另渲一段 6 秒废片只要音轨：角色卡 + **本人音色参考** + 让他正常说出那句
4. Demucs `--two-stems vocals` 抽人声 → 去首尾静音 + `loudnorm=I=-18` → ffmpeg `adelay` 按比例混回去

三重验证（山音第 4 镜）：

| | 嘴型（7 帧） | ASR |
|---|---|---|
| 原版 H3 念 | 0.93s、1.58s 嘴张着 | 完了难怪尺寸不对 |
| 无声画面 | 全闭 | **空** |
| 混入心声 | 全闭 | 完了难怪尺寸不对 |

一条心声多两段 H3 渲染，都免费。

### 2.6 白模判定器与验收器（**已做好并标定**）

**判定器** `render/blockout_need.py`，读 `episode_plan.json`，三条件筛：地点可建 → 本集该地点 ≥3 镜 → 镜头点名 ≥2 人或文字有空间关系词。每条判断打印命中的关键词。

诸天全书实测（3841 集 / 70604 镜）：可建 28.4% → 本集复现 28.3% → **最终 25.4%**。要白模的地点 282 个，**建最忙的 20 个覆盖其中 52%**，50 个覆盖 69%。每集地点数中位数 1，一集最忙的地点吃掉中位 100% 的镜头——**房间按地点建，不按集建**。

**验收器** = `blockout_blender.py` 加 `ids` 参数 + `blockout_check.py`。每镜多渲两张 Workbench 平涂 ID pass（带房间 / 房间 hide_render），每个角色一个纯色（红绿蓝黄品青，路人白，房间黑），关抗锯齿，解码就是每通道过 127。不到一秒一张。

四个测量都是确定值，不用视觉模型：在不在画面（像素数）、被挡多少（1 − a/b）、出不出画（包围盒贴边）、占画面多高。

角色分三类，由 `roles_export.py` 从分镜脚本导出：`people/extras`（挂卡，必须可见）、`unseen`（只拍背影，按朝向判）、`placed`（陪坐，只测不判）。**不传 roles 会把在场所有人当必须可见，那是错的。**

标定结果：**18 镜人工验收过的画面里 17 镜通过，唯一不通过的是真阳性**——第 14 镜给余生挂了卡，但他贴左边缘被切掉、还被课桌挡掉 31%。

标定过程中删掉一条规则、改了两个阈值，见 §4。

### 2.8 找到了流水线的门，和门后没建的房间

`plan_chapter_thin.py --storyboard-sheet <xlsx>`：「faithfully import this XLSX sheet as an authored draft; no model calls」。六套技能每个都产出了 `分镜表.xlsx`。

**但六份没有一份能进去**（`check_sheets.py` 用流水线自己的 `read_workbook` 验的），每份缺 7–8 个列。九个死列名是：镜号 / 摄影角度 / 景别 / 画面内容 / 动作 / 场景 / 台词 / 声音 / 机位 / 运镜 / 连续性 / 叙事目的 / 预算秒。

**信息都在，只是列名和切分不同。** 山音离契约最近，九列直接命中四个。

**更关键的是门后**：`import_script()` 的产物是

```
"status": "imported_needs_bindings",
"pending": ["逐镜人物和参考资产绑定", "对白与音效分离及画外/记忆声音绑定",
            "画面起止状态投影", "跨镜声音桥和剪辑预算接入"],
characters: [], turns: [], visual_prompt: "", extras: []
```

代码注释：**「Compilation refuses this draft until a technical binding step is available.」**

**而沙箱的 `conv_fts.py` 正是那个绑定步骤**，一次结构化 Qwen 调用出逐镜 people / lines（带 speaker 和 say/inner/narration/offscreen）/ sound。对着四项 pending：第一、二项做到了，第三项半做，第四项没做。

副产物：**不需要生成 xlsx**。`import_script` 吃的是内存里的 `StoryboardSheet` 对象，不是文件，所以绑定步骤可以从技能的任何产物直接构造它。流水线是用 zipfile+ElementTree 裸读 xlsx 的，**刻意没引 openpyxl**，盒子上也没装。

## 4. 失败和陷阱（**这节最重要，别重蹈**）

1. **官方画外音写法关不掉口型。** 一字不差照写仍然嘴在动。别再靠提示词解决，走 `inner_mix.py`。
2. **景别没法用画面占高判。** 18 镜标定：wide 0.34–0.76、medium 0.36–0.87、medium_close 0.61–0.89、close 0.78–0.95，四档完全重叠（站着的人靠近相机就占满画幅）。`blockout_check.py` 里这条已删，数值仍记进 `scale` 字段。
3. **`open_check.py` 的阈值不通用。** 它在 live2 那轮标定，那轮场景板是 `weak_reference`；六版这轮场景板被声明成「就是本镜的背景」，片子本来就该高度相关，于是大面积误报（社区 10/13、Visual 9/12）。抽查五段：三真两假。**粒子检测只扫蓝紫（色相 190–250），漏金色**——Leos 第 7 镜满屏金色粒子没被标记。换配置必须重新标定。
4. **不能把镜头描述按句号切开当「开场画面」。** 很多镜头第一句只是机位短语（`Deep focus wide shot.`），切出来开场画面一个人都没有，H3 就照场景板画空教室。第一轮六版渲到一半发现，全部重渲。`fix_round.OPENING` 钩子为此而加，`six_round` 传整段。
5. **`VOICE_OF` / `UNSEEN` 这类表容易只配一半。** 之前只配了秦伊和叶伏天（live2 只有这两人有画外镜头），换一批分镜立刻在余生身上 `KeyError` 崩掉，84 段渲到 56 段。加新分镜前先检查这类映射表。
6. **别自己重写画风提示词。** 见 §2.3。要复用某本书的画风，调它自己的生成函数。
7. **同一实验里种子要对齐。** 否则剧本差异和种子运气混在一起。
8. **`set -euo pipefail` + `find | head` 会 SIGPIPE 退出 141。** 用 `mapfile`。
9. **ssh 里套嵌套引号的 heredoc 会被吞。** 代码写进文件再 scp 上去。
10. **不可能的读数先怀疑仪表。** 今天两次：检测器大面积报警、验收器 9/18 不通过，都是阈值错不是片子错。

## 5. 未决的问题

**六版成片里还有系统性缺陷，没解决**：很多段开头或结尾是空教室。原因是不挂白模时房间几何没有别的东西锁得住，所以场景板被声明成 `fully_preserved - 这就是本镜的背景`，而 H3 拿到「完全保留」的参考图就会把它当成一帧播出来。

挂白模的坏法是替身漏出来变成绿色板子；不挂白模的坏法是场景板被当成一帧播。**两边各有各的坏。**

**第三条路没试**：每镜给一张首帧。技能里社区、Leos、Visual、造梦师本来都写了「开场画面（动作发生前一刻）」这一列，Drama 还专门写了「冻结关键帧提示词」。首帧一挂，房间几何由首帧锁，场景板就能降回 `weak_reference`。这也正是流水线四项待办里的第三项「画面起止状态投影」。成本：一版 16 张 gpt-image。
