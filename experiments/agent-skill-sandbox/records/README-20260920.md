**`conv_fts.py` 正是流水线自己标了缺的那一步。** `plan_chapter_thin.py --storyboard-sheet` 能把人写的分镜表导进来，但产物是 `status: imported_needs_bindings`，`characters`/`turns`/`visual_prompt` 全空，`pending` 列着四项：逐镜人物和参考资产绑定、对白与音效分离及画外/记忆声音绑定、画面起止状态投影、跨镜声音桥和剪辑预算接入。`conv_fts.py` 做到了前两项和第三项的一半。把它做成正式的绑定步骤，是这条分支最该先做的事。

`check_sheets.py` 用流水线自己的 `read_workbook` 去读六套技能的 xlsx：**六份没有一份能通过**，每份缺 7–8 个列。但信息都在，只是列名和切分不同（见该脚本输出）。修法是把九个列名写进任务说明，或在绑定步骤里做列映射——不需要生成 xlsx，`import_script` 吃的是内存里的 `StoryboardSheet`。

## 这一天得到的、写进代码的结论

- **内心独白按官方写法写，关不掉口型。** `says in an off-screen voiceover` + `while their lips remain completely closed` 一字不差照写，抽帧仍能看到嘴在动。可靠做法是 `inner_mix.py` 那条工程路径。
- **景别没法用画面占高来判。** 拿 18 镜人工验收过的画面标定：wide 0.34–0.76、medium 0.36–0.87、medium_close 0.61–0.89、close 0.78–0.95，四档完全重叠。`blockout_check.py` 里这条规则已删，数值仍记录。
- **不能把整段镜头描述按句号切开当「开场画面」。** 很多镜头第一句只是机位短语（`Deep focus wide shot.`），切出来的开场画面里一个人都没有，H3 就照场景板画空教室。`fix_round.OPENING` 这个钩子就是为此加的。
- **技能写的分镜里直呼人名会多画人。** 84 镜里 78 镜直呼 `Ye Futian` 这类名字，而同一个人已经是 `<Subject 1>`。`six_round.NAMED` 在构建时换成角色描述。
- **比喻会被照字面画出来。** `fix_round.FIGURATIVE` 拦下 28 处（`face freezes into a mask of ice`、`eyes light up`、`holy ground`），`six_round.FIGURES` 给出每一处对应的可拍动作。
- **`VOICE_OF` / `UNSEEN` 这类表容易只配一半。** 之前只配了秦伊和叶伏天，换一批分镜进来立刻在余生身上崩。
