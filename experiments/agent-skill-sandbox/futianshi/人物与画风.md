# 人物与画风

## 画风

- 照参考视频《一表千金》（小云雀制作）的画风：**唯美精修的美型半写实 3D CG**，像 3D 乙女游戏的过场动画。
- 人物：偶像式的美型脸；皮肤白皙光润，带柔和的光泽；眼睛适度放大、有神，虹膜清晰，有眼神光；鼻子小巧精致，嘴唇柔润；头发是大块柔软的发束，细碎的发丝透光。
- 光线：柔和的主光，加暖色轮廓光和轻微的光晕，浅景深。古装的布料、配饰细节清楚，但干净，不粗粝。
- 不是扁平卡通，不是朴素的 3D 游戏模型，也不是照片；没有描边。
- 画幅：16:9 横屏。

## 人物（本章出场）

人物的具体造型还没有定稿（之后会按下面的描述画角色卡），分镜里按这里的描述写，不要另加设定。

**叶伏天**（主角）
- 十五岁的少年，入青州学宫三年，体型偏瘦。
- 线条清晰的英俊面孔，一双干净深邃、灿若星辰的黑眸；平时一副懒洋洋、玩世不恭的样子，认真起来带着一点轻狂的自信。
- 三年来一直停在觉醒第一重聚气境，在学宫里是出了名的"废柴"；自称天命法师，说自己的命魂还在沉睡。

**秦伊**
- 十七岁，青州学宫的正式弟子、外门弟子讲师，人气最高的讲师，被许多弟子奉为女神。
- 容颜美貌，一身青衣长裙，步态优雅；平时冷若冰山，生气时脸上像结了寒霜。
- 三年前叶伏天测出天品感知天赋时她就在场，一直暗中关注他，所以对他不求上进格外恼火。

**余生**
- 叶伏天形影不离的兄弟，坐在学舍最后面的角落。
- 寡言、冷淡，眼神锋利；天赋绝伦（金系属性感知天品，可法武兼修），境界比许多讲师还高。
- 只听叶伏天的话：叶伏天一句"坐下"，他就安静坐下。

**晴雪**
- 十五岁的清纯少女，坐在叶伏天身后，是她出声叫醒了叶伏天。

**学宫弟子**
- 一屋子十几岁的少年少女，是围观、议论和起哄的群众。

## 场景

- 青州学宫的一间学舍（讲堂）：前面是讲台，一排排书桌坐满了学生；时值秋天。本章的戏全在这里。
- 青州学宫外景：原文开头对青州城、青州学宫的介绍，可以用一个学宫外景的建立镜头交代。除此之外不另开场景。
