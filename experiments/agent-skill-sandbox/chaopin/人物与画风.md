# 人物与画风

## 画风

- **3D 国漫 CG 动画**，三维渲染、PBR 材质：简化雕塑式的东方面孔，自然人体比例，哑光细腻的皮肤，束状建模的发丝。
- 布料、木石、金属有真实的体块和克制的高光；电影化的体积光和分层景深。
- 整体接近《凡人修仙传》《斗破苍穹》这类年番的三维国漫质感。
- 角色必须是一眼可辨的动画角色造型：眼睛略大、五官简化概括、皮肤光滑。不是真人照片，不是写实渲染。
- 画幅：16:9 横屏。
