# 《将死之人》：先把故事讲清楚

本轮交付表达稿，不启动新图、配音或视频生成。原片仍选《雾月秘典》第1集，来源的视觉审查没有问题标记；新改编的连贯性必须重新判断，不能继承原片的 `pass`。

## 对首轮样片的判断

用户反馈：不能看、不连贯、看不懂，分块莫名其妙，不知道想表达什么。这是对成片可用性的否定，优先于格式和语音覆盖检查。

本轮失败不只是画面不够精致：

1. 将同一画面重复裁成三格，观众不知道这些格子是先后发生、同时发生，还是在看不同人物；局部裁切也没有提供新信息。
2. 从既有视频按估算时间抽帧，没有保证抽到的状态对应正在讲述的事件，配音和画面各说各的。
3. 把现有视频分镜直接当作漫画脚本，没核对完整原文。原文中解决语言障碍的“现在，你有了”以及“等来信并烧掉”的遗产条件没有被恢复，关键因果断开。
4. 主角心声被当成普通对白读出；脑内女声只显示“无名女士”，没有让观众知道声音来自哪里。
5. 约46.18秒配音被填充到82.32秒展示时长，新增约36秒间隔并没有相应戏剧动作或阅读内容。数字上的等长压过了叙事节奏。

## 这一集讲什么

**莱恩突然来到陌生世界，被一个濒死男人紧抓着手。他必须装作这个身体的原主人，先弄清状况；脑海中的女声帮他获得语言知识，而男人交代的遗产条件，是等到三个月后的9月5日，将收到的信烧掉。**

主角眼前的目标是“能够回应，问清身份与处境”；阻碍是“不认识对方，听得懂却不会说”；本集的转折是“女声赋予语言”；结尾的新悬念是“这份遗产为什么要求烧掉未来的一封信”。

不必在这一集解释女声的真实身份，也不必堆叠历法和世界观术语。必须让观众知道女声在主角脑内、它让主角获得了语言知识，以及遗产的具体交换条件。

## 表达方法

以单个全屏主画面顺序切镜为主。先交代两人的位置，再使用手腕、眼神和煤气灯等局部画面。观众一次只需要关注一个叙事重点。

固定空间关系：莱恩在画面左侧的床边，病人在右侧床上，病人的右手握住莱恩右手手腕。转入特写后保持动作、视线和光线方向。不能把一个手部裁图放上来，让观众猜是谁抓着谁。

默认不分格。只有两个不同画面必须在同一时刻建立明确关系时才短暂使用两格，并写清用途；这一集的第一版分镜用顺序切镜就能成立，无须分格。

画面承担空间、动作、人物关系和反应；声音承担时间跳转、内心目标与语言能力变化。旁白不逐条朗读舞台指示。

四种声音明确区分：

- 旁白：简洁交代穿越和处境，主要用于开头及必要的因果衔接。
- 房间对白：病人和莱恩实际对外说的话，与人物表演对应。
- 莱恩心声：他未说出口的判断、请求；画面里不做开口讲话动作。首次出现时可短暂标注“莱恩心声”。
- 脑内女声：首次明确标注“脑海中的声音”，环境声稍退、主角停顿作反应；不画一个不存在的女人站在房间里。

字幕通常一至两行跟随当前话语，不再使用占据下方大面积的角色名和文本框。主画面始终承担叙事，不把它做成说明文字的背景。

## 完整镜头表达稿

以下时长只用于估算节奏，约85–105秒；先确定自然台词与必要动作，再定时长，不强行填到82.32秒。方案2与方案3将共用同一份新脚本和声音。

| 段落 | 画面与切换 | 声音草稿 | 这一段新增的信息 |
|---|---|---|---|
| 1. 突然被问住，约0–9秒 | 先给能看清两人和床的位置的中全景。病人抓着莱恩手腕，莱恩刚回过神。再切抓握特写，接莱恩看向病人的反应。 | 病人：“我说的，你都记住了吗？” | 谁在对谁说话，主角正被对方控制着，必须作答。 |
| 2. 他不属于这里，约9–19秒 | 莱恩的视线引出煤气灯、铜管和旧卧室的短镜头，再回到莱恩，病人的抓握仍持续。没有另开一个陌生场景。 | 旁白：“上一刻，莱恩还在为朋友处理后事。再回过神，他已身在一间陌生的卧室。”莱恩心声：“这是……穿越了？” | 他为何茫然，不认识眼前的人和环境。 |
| 3. 想回应，却说不出来，约19–31秒 | 莱恩看向病人，张口欲答，声音没有出来。病人盯住他，握着的手没有松开。 | 旁白：“他决定先弄清状况。可这陌生的语言，他听得懂，却不会说。” | 主角的目标和具体障碍；这里不能让他对外流利说出“我不会说”。 |
| 4. 脑内出现声音，约31–43秒 | 留在莱恩脸上，他侧耳、停住。房间环境声退后，病人仍在原位。女声说话时不引入新人物形象。 | 脑内女声：“你来到了这个阴暗的世界。”莱恩心声：“我想要接纳这身体的一切，但我没有这身体的记忆，没有这身体的语言习惯。” | 女声来自脑内；主角向它求助。 |
| 5. 女声给了他语言，约43–54秒 | 女声回应后，莱恩短暂痛苦、吸气，随后重新看向病人。人物状态由无法回应变为努力组织语言。 | 女声：“现在，你有了。”旁白：“涌进来的不是记忆，而是一门语言的知识。” | 前一个障碍如何被解除。这句回应和结果不能省掉。 |
| 6. 回答成功，约54–65秒 | 回到床边两人关系。莱恩看向病人说话，措辞和停顿略生硬；病人把这种迟钝当作原本就有的表现。 | 莱恩：“抱歉……先生，我状态有些不好。您是否可以重复一遍……您让我记住的事情？”病人：“你还是这个样子，脑袋不太好用……好吧，我再说一遍……” | 他确实能够说话了；原主人本就反应迟钝，暂时没有露馅。 |
| 7. 遗产并非白给，约65–83秒 | 病人的近景为主，间插莱恩低头听、不敢直视的反应。同一卧室内完成，不另画一场已发生的“签约”。 | 病人：“我就要死了。我提前三个月知道自己将要死去，所以从流浪汉中选中了你。在我死后，你将获得我的一切，我的调查事务所，我的所有财产。” | 为什么这个男人找上他，以及将给他什么。 |
| 8. 真正的要求，约83–结束 | 病人的手再次收紧；莱恩轻微挣动但没挣脱。病人说出条件后，停在莱恩避开视线的反应，结束。 | 病人：“继承我的调查事务所，至少要维持这里一直营业。直至三个月后的1853年9月5日，你会收到一封信。将信取回来烧掉。这就是你获得我的全部遗产的代价。” | 明确的未来日期、具体行动和交换条件，留下为什么要烧信的悬念。 |

“信”此时还没寄来，不能为了补画面把它画成桌上的现有信件，更不能提前播放主角烧信。日期可以作为一句短字幕辅助记忆，但须和病人的台词同时出现。

## 对原文的恢复与改编边界

- 开头的“处理朋友后事后突然来到陌生卧室”来自原文第一段，使用压缩旁白。
- 听懂但不会说、准备扮演原主人的处境，来自病人第三次提问后的段落；改为旁白和心声，不当作外部对白。
- 保留女声“现在，你有了”，并明确获得的是语言知识，原身体记忆没有回来。
- “从流浪汉中选中”“给了新的名字”“遗产”属于病人所说的原主人的经历，不能旁白说成穿越者亲身经历过。当前镜头稿保留“从流浪汉中选中”，称呼来源可由随后病人的称谓自然确认。
- “维持事务所营业到三个月后的1853年9月5日”“取回并烧掉届时收到的信”是同一个遗产条件，必须完整保留。
- 台词草稿中的删节是保序压缩，后续配音稿应逐句对照原文记录原句与删节；不增添实际签约、现在就拿到信、已经同意交易等原文未发生的动作。

## 两种方案如何区别

方案3先把这条声画叙事做成单画面顺序切换：两人关系、被攥住的手、环境线索、主角反应、病人交代条件，每一张图都是明确的剧情状态。只有图片承载的信息需要观众看近时才做轻推，不对所有图片套同一种运动。

方案2沿用完全相同的镜头和声音，只考虑把三个需要动作连续性的地方换成视频：开头的抓握与反应、语言知识涌入后的身体反应、结尾的再次握紧与挣动。这一章以悬疑对话为主，20–30秒只是原先的资源预算，不是必须填满的指标；静帧已能讲清的部分保留静帧，视频以实际表达增益决定。对话尽量用反应镜头承接，嘴部明显入镜时必须解决音画匹配，不能直接盖上新配音。

素材按镜头稿找或做。已有画面若没有清楚的两人关系、手腕抓握或所需人物状态，就补对应剧情图；不再按旧视频时长比例抽帧，再用旁白解释碰巧抽到的画面。

## 下一轮先验证什么

先用可读的静态分镜和声音草稿检查两条链是否成立：

1. 被追问 → 想回应 → 无法说话 → 女声赋予语言 → 能够回应。
2. 病人预知死期并选中原主人 → 交付遗产 → 保持事务所营业 → 指定日期来信 → 烧掉信。

观众应该能自然复述这两条链。做到这一点后，再看哪几个动作值得使用视频、漫画部分会损失多少表演感，以及新生成素材需要多少成本。技术格式和字幕识别通过只说明文件与声音能工作，不能替代这个判断。
