# 参考图怎么挂给 H3（2026-09-20 对照实验）

一句话：**参考图看不到的部位，模型就自己编。** 所以挂图的规则是"这一镜要拍到的部位，都得在某张参考图里出现"，而不是"挂得越少越省"或"拼成一张越方便"。

## 实验

沙箱 `tmp/agent-sandbox/render/ref_round.py`。同一个角色、同一个房间、同一段描述、同一组种子，**唯一变量是参考图怎么打包**。3 镜（正面说话 / 侧身转头 / 走到门边）× 3 组 × 2 种子 = 18 段，走本地 H3 ref2va。

受控到像素：角色的半身图和全身图**就是那张两格表的左右两半**（实测平均差 0.2/255）；地点的四个方向也从同一张四格板现切，三组共用同一批像素。

| 组 | 角色 | 地点 |
|---|---|---|
| `sheet` | 两格表整张 | 四格板整张 |
| `both` | 半身 + 全身两张，各写职责 | 该方向一张 |
| `picked` | 这一镜该用的那一张 | 该方向一张 |

## 结果

| | 参考卡被拍进视频 | 房间视角拍错 | 房间还原度 | 服装细节 |
|---|---:|---:|---|---|
| `sheet` | **2/6** | **1/6** | 0.43–0.77 | — |
| **`both`** | 0/6 | 0/6 | **0.80–0.96** | **宽腰带＋结，接近卡** |
| `picked` | 0/6 | 0/6 | 0.80–0.95 | 腰带偏窄 |

- **拼图会被当成画面结构复制。** 一段前 2 秒画面就是那张角色卡本身（灰背景、左半身右全身），2 秒后才叠化进场景；另一段整段被切成两格，每格一个房间视角、各站一个他（等于克隆）。
- **总表即使挑对方向，也只是"重建一个差不多的房间"**，不是还原那张板。六对之间完全不重叠（`picked` 最低 0.80 > `sheet` 最高 0.77）。
- **只挂一张会丢裁切线以外的部位。** 只给半身照的那一镜，腰带被画窄了——半身照裁在胸口以上，腰带不在参考里。

**"带上防拼图措辞"救不了。** 三组的 `detailed_description` 都写了 `no cut, no split screen, no border and no inset`，retention 也写了"sheet 的版式不属于目标场景"，总表组照样分屏、照样把卡拍进去。和 `docs/` 里既有的结论一致：H3 见到否定项反而容易画出来，**正面描述才有效**。

检测不需要视觉模型：首帧对参考图做灰度归一化相关即可（干净片 −0.12…+0.17，污染片 0.82 / 0.97）。脚本 `render/contam.py`、`render/viewchk.py`。

## 落到本仓库

**流水线不用拼图，这条不用改。** `asset_prompts.character_prompt` 明写「不要多视角设定表、分身、镜像人物、局部小头像或拼贴」，地点也是一个视角一张。实验只是确认了这个选择是对的。

**两张卡各画了什么：**

| 文件 | 提示词要的 | 能定什么 |
|---|---|---|
| `turnaround.jpeg` | 「单人四分之三正面、**从头到脚**的选角定妆照」 | 身体比例、服装版型、主色、配饰 |
| `expressions.jpeg` | 「四分之三正面单人**胸像**…肩颈与服装领口完整」 | 五官、发型、年龄感、肤色 |

`application/packing/assets.py` 的两图绑定文案**原先把这两个职责写反了**：让胸像去定"身体比例、服装版型"——而它裁在领口，根本看不到。2026-09-20 已对调。因为两图分支在生产里从不执行（见下），这次修改不改变任何已渲片段的请求哈希，**不触发重渲**。

**两图分支现在是死的。** 两个门都要环境变量 `NOVEL_TWO_VIEWS=1`，而 `.env`、`configs/`、`scripts/` 里都没有它（全仓库只有测试设过）；快车道的 `two_view_cast_limit` 还是 0。所以生产是**每个角色只挂 `turnaround.jpeg` 一张全身照**。

## 还没做 / 没测

- **没测"只挂全身照的特写镜头"**。那是生产现在的常态，风险是镜像的：全身照上脸最小，特写可能拿不准五官。要开两图之前，应该先补这一组。
- **把 `NOVEL_TWO_VIEWS` 从环境变量挪进 `profile.json`**（例如 `two_views: off|leads|all`，默认 off）。环境变量是隐形开关，容易出现"某次跑带了、某次没带"的不可复现。
- **腰带那条只有目测支持。** 试过用取色计数量化，取色距离把群演的灰蓝校服全数进去了（他们占大半画面，腰带只几百像素），三组读数无差别——指标测的是"画面里有多少灰蓝"而不是"腰带在不在"。没有继续调阈值。放大并排图由 `render/zoom.py` 生成。
- n=2/格。污染率 2/6 的置信区间很宽；可信的是房间还原度那条（六对不重叠）。
