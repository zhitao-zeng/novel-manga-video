## 实际改动

| 原来的处理 | 现在的处理 |
| --- | --- |
| 单字人名要满足特定自我介绍句式，另有夫人、身影、少年的词尾规则 | 从原文语义识别主体、名字、局部称谓和当时形态；用真实原文区段保存依据 |
| 旧人物词典先进入模型，牵引人物判断 | 原文识别阶段不提供旧词典；完成后匹配身份库，明确的人名优先于冲突的旧别名 |
| 分镜、打包、修段各自推断别名 | 共用章节 `identity_context.json`；角色、说话者、动作主体/对象、聊天对象统一采用该章绑定 |
| 原始别名表可直接把分身折叠成本体 | 分别行动的源主体不能仅因旧别名指向同一行而合并；无法唯一匹配时保留未匹配状态 |
| 切书后全局别名和匿名声线继续累积 | 加载下一本书时清空上一本书的状态 |
| 遇到“龙／雪铠”就把“三头”机械替换 | 删除物种词表及替换函数；规划、修段与英文编译分别表达独立身体数量、一个身体的头数 |
| 星海全书默认直立人形、相似角色豁免、特定三头龙一个头也可放行 | 美术说明仅解释画风；当前原文、身体阶段和动作归属优先，无全书身份豁免 |

## 数据和代码的边界

人物库、别名候选、成长阶段和已有身份账本仍是本书资料，不需要删除所有字典。旧资料仅用于检索；有当前章节解读时，没有得到该次解读支持的旧别名不会直接成为替换规则。

已接受且到达生效章节的账本关系可以统一身份。模型临时提出的分身、附身或同人关系不直接写成全书合并命令。更新人物资料后可以复用原文识别结果重新匹配；原文变更则重新读取。准备状态也会因身份账本更新而失效。
