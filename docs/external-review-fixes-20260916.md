# 外部审查问题修复 · 2026-09-16

本次修复针对空人物缓存、局部修段后的地点切分，以及重写画面对原文明示形态的违背。没有重规划全书，也没有为验证额外生成视频。

## 已落地的行为

- `story_identity.py` 不再接受未经确认的空人物结果作为有效缓存。空结果触发一次独立抽取/确认；未确认就报可重试的抽取失败，不能误标成原文损坏。真正的纯景物章节可保存明确的无人确认，随后直接复用。
- `plan_chapter_thin.py` 移除人物库前八人的兜底。原文主体尚未绑定人物库时给出具体姓名，不用无关人物替代。纯景物的空人物数组有有效 schema；修段入口也去掉前十二人的兜底。
- `clip_readiness.py` 检查片段是否跨地点。旧显示名称与已正确改绑的场景参考不一致，单凭这一点不触发重拍。
- `repair_clips_thin.py` 遇到地点边界变化时，调用 `repair_blocked_plan.py` 只重新打包相关、共享原始分镜的片段范围。保留对白顺序和来源索引，未涉及片段保留完整请求和英文缓存。新片段编号避开已有计划和媒体目录。
- `source_recheck_thin.py` 不将旧切法的视频当成新切法验收。`managed_repair_thin.py` 为全部新切片段准备英文请求并记入修复历史，避免漏掉新编号。
- 重写后、保存/生成前增加局部形态核对：仅在该段存在原文外貌证据且候选确实有修改时调用本地文本模型。人物卡、旧抽取的外貌概括、姓名/称谓猜测不作为事实。阻断须同时提供原文和候选画面的实际引文；无法举证的检查结果按检查失败处理。矛盾或检查失败会撤回候选修改，不消耗视频生成次数。
- 将卡片构建中的类型文件读取移到循环外，并补全两个配置文件的末尾换行。
