# 质量问题分类与规划修订决策 · 2026-09-17

本轮完成后续建议的第 1、2 项：集中质量问题分类，分开规划校验与修订决策。状态刷新/发布拆分及渲染重试职责不在本轮范围。

## 质量问题只定义一份

`media/issues.py` 集中定义问题代码、语音/画面类别、片段/成片范围，以及是否由语音复核重新计算。分析器只产生问题；语音门调用同一份分类和纯策略函数，不再另外维护问题字符串名单。

既有 `missing_..._over_...`、语音能量、额外发言、导演备注被读出、无台词人声、黑屏、成片静音检查使用原有报告代码。未知问题仍按原规则处理，语音仅记录时不会放过黑屏或其他技术问题。不改门槛数值、不改变忽略项的顺序，不新增落盘格式。

## 规划诊断与决策

- `planning/issues.py`：`PlanningCode` 定义问题及修复范围；`PlanningIssue` 携带原文案、阶段、区段和字段。`ValidationResult` 返回问题、警告和规范化镜头。
- `planning/validation.py`：保持原有检查和规范化算法，在发现问题的位置直接产生上述诊断。原文案仍用于报告和模型反馈。
- `planning/decisions.py`：决定局部补段、整章重写、接受及既有最后一轮豁免，并生成原有修订反馈。
- `planner_flow_thin.py`：执行选定动作、扣减原有补段次数/时间、保存请求和报告。移除对自然语言报错和 `UNCITED_ERROR`、`STAGE_ERROR`、`CLIP_LEVEL_ERROR` 的解析依赖。

本轮明确消除的文案耦合：修改一个已登记问题的说明，或者引文里出现 `unknown location` 等文字，不再改变它的修复范围。演员表和地点问题仍要求整章重写；单阶段问题仍局部处理；未引用区段使用显式区段编号。没有新增人物合并、动作猜测或更严格的交付门槛。

保留首次校验之后才可执行的最后一轮时长下限豁免；补段之后新出现的下限问题不额外豁免。严格门、补段次数、累计时间上限、截断反馈和重复旧稿处理维持原顺序。
