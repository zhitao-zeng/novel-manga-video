# 诸天资产检索与修复入口问题 · 2026-09-16

本次检查确认：部分低通过率来自资产查找与补齐流程的错误，不能归为视频模型没有按提示画好。资产缺失时直接重写受限演员名单，无法得到正确人物。

## 已证实的根因

`thin_review.name_matches()` 原先把姓名互相包含视为已经存在。实际库里有单字条目，导致：

| 原文需要 | 当前人物库有无同名条目 | 旧补库命中的条目 |
|---|---|---|
| 吴龙 | 无 | 吴、龙 |
| 问天 | 无 | 南宫问天、天 |
| 雷啸天 | 无 | 雷啸、天 |

原文身份读取保留了这些未匹配主体，但补库跳过它们。修段的演员和说话者 schema 又只允许人物库已有名字，形成“认为已存在 → 无法取到 → 受限名单内反复改写”的失败路径。

第 2339 章原文明确有金大升、吴龙两人化形、跪拜。吴龙没有库条目，旧剧本使用杨显。第 2131 章问天没有可用的原文绑定，旧剧本使用土肥圆。这里不能通过增加重拍次数修复，也不能仅凭名字包含就把问天绑定南宫问天；身份关系仍需原文确认。

13:42:49 扫描待修改章节的已有身份记录：144 章至少有一个未绑定的在场个体；其中 113 章涉及旧包含匹配会跳过、精确匹配不会跳过的主体。此数不是“113 章全部只因这一处失败”，也不表示所有主体都需要独立新卡；其中包含别名和临时角色。

## 已完成的代码修改

- 资产存在判断改为忽略空白后的精确相等。
- 姓名包含关系只用于补库模型的候选检索，不用作同一身份判定。
- 已存在的明确别名继续复用。
- 模型返回不完整的 `same_as` 名称时，不再用字符串包含去任意选一个长名字注册别名。
- 新测试覆盖单字误命中、长短名字、室内外地点、换行姓名、重复运行不重复补人、明确别名复用，以及无效别名目标。

## 尚未解决的流程缺口

`thin_batch.grow()` 在原始规划前补库；已有计划且未要求重规划时跳过。`prepare_h3_book.py` 的旧剧本审查/局部修段不调用补库，`repair_clips_thin.py` 仅从已有库筛选演员。

因此，本次修正存在判断并没有自动注册存量缺失人物、生成新卡或修好全部受影响章节。完整资产恢复需要先区分：已有资产的别名/阶段、真正的新角色、仅本场出现的无名角色；然后补齐可用绑定和必要的形态资产，再进行局部改稿。不能把所有未绑定称谓直接变成全书通用角色，也不能拿其他人物卡替代。

本次未批量修改人物库、未重画角色卡、未停止生产，也未提交或推送。核对了阿紫、阿曜兽形的现有参考图；仅看图片并不能证明其全书各阶段均正确。
