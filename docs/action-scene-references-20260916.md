# 动作引用支持场景对象 · 2026-09-16

《圣堂》第 1 集第 14 阶段原文是沈行舟挥铲迎击扑来的野山羊。剧本的 `extras` 已有“灰色野山羊”，但 `actions.target` 是“沈行舟”，规范化又将三元动作拼成“沈行舟挥铲砍沈行舟”，进入 `clip_06` 的主要事件。

现行 schema 原本已经允许空字符串。实际缺口还包括：提示词要求动作双方必须在 `in_frame`；目标被限制为人物枚举；规范化清空非人物目标、丢弃非人物发起者；修段也沿用同一限制。因此只增加空字符串并不能打通路径。

## 改动

- 规划与修段的动作 `actor`、`target` 改为有长度上限的字符串。允许具名角色、场内 extras 描述、动物、道具、环境对象，以及没有受事时的空目标。
- 提示词明确不要把没有目标、无法确定目标或库外对象默认替换为主角自己。
- 保留动物/物件的动作与目标；只有确实匹配角色名的项才参与人物引用，不为山羊新建人物卡。
- 显式 `in_frame` 不被动作引用反向扩充。画外人物可以是动作对象；可见说话者仍须保留在画面绑定中。
- 修段支持只有 extras 的镜头，不再用旧人物名单填回空 `in_frame`。
- 修正动作时剥掉旧的自动拼接前缀，避免新正确句子与旧错误句子同时进入提示词。
- 构图计算识别场内 extras 发起的动作；未明确的发起者不会被替换为另一个可见人物。
- 不禁止所有 `actor == target`：原文确实描写包扎自己等反身动作时仍合法。
