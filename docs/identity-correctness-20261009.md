## 共用实现

1. CLAIM_TYPES 的含义统一；same_as 的两端必须是同一个具体人物，不把亲属、师徒、夫妻当成身份。终裁看到两次判断及理由。已确认 named 和原文证据优先，名字长短不决定是否泛称。
2. 请求异常与语义 unknown 区分，异常不缓存为猜不出的身份，不提交本章半成品。失败恢复内存，成功 raw 缓存可续用。复审缓存按既有文件状态刷新，并存本段实际身份快照；视频未变但相关身份改变时重新判语义，复用已有视频识别结果。
3. 人工决定按原始关系定位。撤销合并后只重建受影响的身份组，重放仍成立的原始关系两端，保留相邻确证。若其余接受关系仍把两端连在一起，报告矛盾，不悄悄删除其他决定。
4. 名单对账 --fix 只采用 raw 中有显式 kind/named 且原文引句可定位的记录，不再把名单里的描述或声音一律播种为具名人物。缺双边对象的 same_as/reveal 留 pending；合法单边事件不等同已确证身份。
