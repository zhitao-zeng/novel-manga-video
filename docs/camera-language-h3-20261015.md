# 镜头语言手册接线与 H3 实测

## 结果

后续更新：手册50项中实际覆盖12项，38项未测；累计18条，新增4条只改逐镜画内描述的同种子复核。新过肩构图、垂直顶拍和目标焦点转换均有明显改善，但顶拍仍多人物，眩晕变焦仍拍错角色。下文前14条是初轮历史结果，不能据此认定H3不支持顶拍或拉焦。

镜头手法已整理为[一份制作手册](../skills/episode-production/references/camera-language.md)，覆盖机位构图、摄影机运动、焦点与光学效果、组合揭示、剪辑衔接，附原创中英文提示片段与来源。普通编剧、导演拆镜、作者分镜任务和 source Agent 共用简短选型提示；制作 Skill 按需读取完整手册，不在每次正常模型请求中重复整份长文。

H3 首轮12种手法各生成8秒，另对顶拍与拉焦各做一条同种子指令顺序复核，共14条、112秒请求量。14条都实际生成并完成全视频与音频解码；模型执行摄影意图的结果有明显差异，不能把技术生成成功报告成全部内容通过。

固定观察、背后绕前、推近的主要效果可见。环绕部分符合；前景人物构图容易出现副本，严格顶拍、目标拉焦、指定演员跟拍和眩晕变焦未在这些样本中完成。

## 接线

- `story/fields.py` 的共用相机说明加入构图、焦点与选型提示；普通首稿、本地方法、导演稿及 source Agent 的现有接缝共同使用。
- 作者分镜任务移除拉焦的通用禁令，仍遵守已有片段时长和声音接口。J/L-cut、声音桥属于剪辑安排，不因手法手册而变成跨请求音频能力。
- Skill 入口与 authoring 资料路由到 `references/camera-language.md`；安装清单实际复制该资源到工作区，Skill 版本更新为 `2026-10-15-camera-language`。已有候选、输入、拍摄次数与预算保留。
- 新增回归覆盖手册实际安装，以及刷新旧手册时保留输入、候选与历史。冻结修复请求仅更新共用提示；同步继承提交 a2b50e9 已修改的作者切镜文案与相应字符长度，没有修改该提交的编译行为。

## 实测条件

使用既有池 `configs/h3_pool.json` 中当时可用的 GPU052 四卡实例；运行时 `/health` 与 `/v1/models` 均成功，模型别名 `minimax-h3-ref2va-turbo`，返回 BF16 DiT / FP32 VAE、4 GPU。请求544P、16:9、8秒，9个 sigma 点、flow shift12、audio shift3，单请求单输出；这记录请求参数，不额外声称现场去噪前向次数已由服务日志确认。

复用光明人物库的两张已有人物全身卡与傲世的一张空石台场景卡，复制到本实验 references 后固定。它们在实验中扮演两名测试演员，情境为原创摄影测试，不写入原书剧情、人物资料或任何生产集数。没有新生图、声音克隆、付费文字模型调用、服务重启或模型部署。

首轮沿现有 provider 按请求派生种子，不作为跨手法成功率或速度 A/B。顶拍、拉焦的两条复核分别复用其原种子、参考图与参数，只将原有相机描述移到场景/表演之前；已核对前后提示的词项一致。

使用生产的 H3 六段编排与参考绑定器，再调用现有 LocalH3MediaProvider；遵守既有全局24槽和每实例2槽，实验自身并发2。首轮12条全部完成，实际文件时长各8.032秒，首轮提交至收口约173.88秒，包含共享队列与下载，不作为模型纯推理测速。

## 逐镜画内描述复核

原实验正文统一先铺陈两人、整个平台、远山与夕阳，再追加局部构图或焦点控制。文义并没有强制两人全身都入镜，但没有充分区分全场存在与当前取景，成为需要检验的提示设计因素。四个新样本保留原主体定义、summary、retention、声景、三张参考、采样参数及各自原种子，只改镜头正文；不更换参考图或重抽种子。

| 手法 | 新正文的主要变化 | 实际变化 |
|---|---|---|
| 过肩 | 先写前景只占甲肩/后脑，乙胸像占另一侧，背景只留当前crop的一小块 | 人物副本消失，过肩关系成立；灰背景和额外嘴部动作仍不合要求 |
| 顶拍 | 画面四边都由地面填充，人物以头顶/肩/脚的俯视缩短轮廓出现 | 真正垂直顶拍出现；甲乙各两份，人数仍错 |
| 拉焦 | 固定局部构图，清楚描述近帽沿/远脸的两个清晰度端点 | 近清远虚→近虚远清可见，背景甲副本消失；仍有轻微构图与背景偏差 |
| 眩晕变焦 | 只取乙脸肩，明确脸占画面比例、后拉与反向变焦 | 近景却换成甲，未确认目标复合运镜 |

结论限于：这些prompt内容会影响同输入、同种子的结果，原失败不能直接当作能力上限。多句正文一起改写，未分离单个词、参考图构图影响、角色绑定与复合运动控制。测试是人工设计提示词经生产H3编排器发送，尚非编剧自主选型或整集测试。
