# 看板进度可视化 · 2026-09-16

用户要求恢复进度条、柱状图，优先电脑端现有内网看板。

- 页首按小说展示可点击的进度概览；点击跳到该书。
- 每本书用百分比、已交付/总集数和分色进度条展示交付、待生成/复审、内容待修、收尾、开拍准备。
- 默认展示交付净增柱状图，可切换 1/6/24 小时，分别按 5/30/120 分钟分组；刷新保留用户选择。
- 柱子支持鼠标、键盘和点击查看采样区间；负增长保留为红柱，采样不完整使用虚线，缺数据留空。
- 运行中的章节任务分为开拍准备、修复准备、生成合成、内容复审；共享 H3 请求池单独标明。
- SD2.0、SD2.5 审查以及 ModelScope 远端已提交数量都有进度条。
- 技术指标和详细表格可展开，旧的合成时间历史图继续保留于历史详情。

柱状图来自 `monitor_metrics/net_delivery.json` 的可交付数量采样变化，不使用文件合成时间冒充净交付。
完整时段共享边界采样点，避免重复计算。缺少连续采样的时段仅显示实际测得的部分，不推算中断期间的产量。
初次加载可直接读取已有采样，不等待较慢的修复详情缓存；该路径不改生产状态。

相关 21 项测试通过，覆盖时间桶边界、负增长、缺数据、进度分类及首次加载。
电脑端 1440 像素实测：3 个主进度条、6 张柱状图、3 个页首概览、2 个 SD 审查进度条，
无脚本错误或横向溢出；时间切换、自动刷新保留选择、展开详情正常。

已通过原守护脚本重载现有 18900 看板服务，没有新增公网服务。
