## Skill如何更新

`prepare_inputs`每次安装当前代码附带的episode-production Skill。维护者在修改其行为指导后更新`session.SKILL_REVISION`；manifest/current-task提供该版本。旧会话遇版本或任务指令变化时只刷新一次对话，保留候选、原会话归档和预算。

案例自动记录不等于自动修改全局Skill。新案例先保留具体问题、操作和观测结果；可复用经验经证据复盘、通用修复及回归验证后再进入共享手册。未完成、仅生成/合成/上传、空finish均不能证明内容修法成功。旧日志缺失的具体修法不臆造补回。

操作指导集中在repair-playbook；case-lessons保留观测及限制；payload由output-contract定义；模型路由、时间和额度以宿主当前返回为准。去掉旧模型名和写死的恢复时长/次数，压缩重复的初始及续跑提示。
